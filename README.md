 PawConnect is a Java-based pet adoption and pet care application developed using Maven. It
consists of two modules: Admin and User. The Admin module allows managing pet listings, viewing
registered users, tracking adoptions, and performing CRUD operations on pets. The User module enables
users to browse available pets, adopt pets online, receive automated confirmation emails, and download a
digital adoption certificate. The application also includes a pet products module for browsing and
purchasing essential pet care items. PawConnect delivers a user-friendly interface and a complete end-to
end solution for pet adoption and pet care services
